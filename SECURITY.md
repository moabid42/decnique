# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it privately through
[GitHub's security-advisory form](https://github.com/moabid42/decnique/security/advisories/new).
Include the affected version or commit, a minimal reproduction, the security impact, and any
suggested mitigation you have. We aim to acknowledge reports within seven days. If the private
form is unavailable, open a minimal issue asking for a private reporting channel without including
vulnerability details.

Detection gaps caused by an unsupported rule idiom are usually product-correctness issues and may
be filed publicly when they do not expose sensitive rules, logs, account data, or an unpublished
evasion. When in doubt, use the private channel.

## Supported versions

Security fixes are made on the latest released minor version and on `main`. Older minor versions
may be asked to upgrade before receiving a fix.
